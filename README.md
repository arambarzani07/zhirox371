# سیستەمی کاشێری پێشکەوتوو — سوپەرمارکێتی کانی چنار (Retail OS PC)

ئەم پڕۆژەیە سیستەمێکی تەواوی کاشێر، کۆگا، حساباتی کڕیاران و بەڕێوەبردنی سوپەرمارکێتە بە تەلارسازیی مۆدێرنی **React (Vite + TypeScript)** لەگەڵ پاراستنی دیزاینی پەسەندکراوی PC و شێوازی کوردی سۆرانی (RTL).

## تایبەتمەندییە سەرەکییەکان

### 1. کاشێر و فرۆشتنی خێرا (Smart Cashier POS)
- سکانەری خێرای بارکۆد، پشکنەری EAN-13، و بارکۆدی تایبەتی تەرازووی سەوزە و میوە (`27...`).
- سەبەتەی فرۆشتن بە دەستکاری خێرای بڕی کاڵا (+ / −) و فرۆشتن بە دانە یان بە کارتۆن.
- دوگمەی داشکاندنی خێرا (0%, 5%, 10%, 15%) یان داشکاندنی تایبەت.
- پەڕەی پارەدانی کاش بە دوگمەی پارە عێراقییەکان (250، 500، 1,000، 5,000، 10,000، 25,000، 50,000 IQD) و ژماردنی ئۆتۆماتیکی ماوە/گەڕاوە.
- فرۆشتن بە قەرز بە بەستنەوە بە دەفتەری کڕیاران.
- پاراستنی سەبەتە (Park Cart - F7) بۆ ڕاگرتنی کڕیاری چاوەڕوانکراو.
- چاپی دەستبەجێی پسووڵەی ثێرمەڵ (58mm / 80mm) بە دیزاینی ستاندارد.

### 2. بەڕێوەبردنی کاڵاکان و بارکۆد (Catalog & Barcodes)
- تۆمارکردن و دەستکاریکردنی کاڵا بە دانە و کارتۆن.
- دیاریکردنی یەکەی بنەڕەتی (دانە یان کیلۆگرام kg).
- ژمارەی خۆکاری بارکۆد (⚡ بارکۆدی خۆکار).
- خەمڵاندنی ڕێژەی قازانج (% و IQD) بەپێی نرخی کڕین و فرۆشتن.
- هاوردەکردن و هەناردەکردنی بەکۆمەڵ بە فایلی CSV.
- چاپی لیبڵی ڕەفە و ستیکەری بارکۆد.

### 3. کۆگا و وەرگرتنی کاڵا (Warehouse & Receiving)
- چاودێری کۆگا و ئاگاداری کەمیی کاڵا (≤ 10).
- وەرگرتنی کاڵا لە دابینکەران (بە کارتۆن یان دانە) و تۆماری پسووڵەی کڕین.
- تۆماری تەواوی هاتووچۆی کۆگا (Movement History).
- چاودێری بەرواری بەسەرچوونی کاڵاکان (Expiry Monitor).

### 4. کڕیاران و دەفتەری قەرز (Customers & Debt Ledger)
- تۆماری کڕیارانی دەستپاک و حسابی قەرز.
- دانەوەی قەرز (Debt Repayment) بە هاتنەناوەوەی دەستبەجێ بۆ سندووقی شێفت.

### 5. دارایی و سندووق و شێفتەکان (Cash Shifts & Drawer)
- بەڕێوەبردنی شێفتی کاشێر و چاودێری پارەی سندووق (Opening Float + Sales - Expenses).
- تۆمارکردنی خەرجییەکان لەگەڵ پۆل و تێبینی.
- داخستنی شێفت، ژماردنی حەقیقی و دیاریکردنی جیاوازی (زیادە/کەمی).

### 6. ئامێرەکان و پشکنین (Hardware & QA)
- پشکنەری بارکۆد سکانەر و وردبینی EAN-13 Checksum.
- تاقیکردنەوەی پرینتەری پسووڵەی ثێرمەڵ (Test Print).
- تاقیکردنەوەی کارەبایی سندووق (Drawer Kick).
- شاشەی دووەمی کڕیار (Customer Secondary Display Live Mirror).
- پاڵپشتی ناوخۆیی دیسک لە فۆرماتی `D:\SupermarketPOS_Data\backups`.

## دامەزراندن و کارپێکردن

```bash
# دامەزراندنی پێداویستییەکان
npm install

# کارپێکردنی پڕۆژە لەسەر پۆرتی 3000
npm run dev

# بونیاتنانی وەشانی بەرهەمهێنان
npm run build
```
